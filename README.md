# Vectorized Wikipedia Search

Wikipedia’s search function relies primarily on exact text matching, which often fails to retrieve relevant articles when queries do not match article titles or content exactly. This limitation makes it difficult for users to find information without knowing precise terminology. We propose a vectorized semantic search engine for Wikipedia that addresses this problem by representing queries and articles as TF-IDF vectors and ranking results using cosine similarity. Our system encodes the semantic meaning of text, enabling retrieval based on conceptual similarity rather than exact keyword matches. We evaluate our approach on the KeySearchWiki dataset, which provides natural language queries with relevance judgments. Our results demonstrate that TF-IDF vectorization provides a functional baseline for semantic search on Wikipedia, while also revealing limitations in handling complex semantic relationships. This work establishes a foundation for future improvements using neural embedding methods and highlights the challenges of semantic search on large-scale knowledge bases.
